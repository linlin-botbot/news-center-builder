# 安裝 skill 與設定每日通知

依第 5 輪使用者選的工具，給他對應的那一段就好，不要三段全貼。把 `{{…}}` 換成他的設定。

> 各家 AI 工具的介面名稱常常改版。如果使用者找不到下面寫的按鈕，請他截圖給你看，依畫面帶他找；不要堅持書面步驟。

---

## A. Claude

### 安裝專屬 skill

1. 下載 `{{skill名稱}}.zip`（不用解壓縮）
2. 打開 Claude → 左下角頭像 →「設定」→「功能」（Capabilities）
3. 確認「程式碼執行與檔案建立」已開啟
4. 在「Skills」區塊按「上傳 skill」，選剛剛的 zip
5. 開新對話說「今天的新聞」，能產出新聞頁就成功了

### 設定每日自動執行

用 Claude 桌面 App 的**排程任務**（Scheduled tasks）。好處是每天的 HTML 能自動存到電腦資料夾，隨時打開。

1. 打開 Claude 桌面 App，進入 Cowork（或 Code）分頁
2. 在左側找到「排程」（Scheduled），按「新增排程任務」
3. 名稱填 `{{新聞中心名稱}}`，頻率選「每天」（只要平日就選平日），時間 `{{時間}}`
4. 指令貼上：

```
使用 {{skill名稱}} skill，產出今天的{{新聞中心名稱}}。
把 HTML 存到「{{存放資料夾}}」，檔名用今天日期。
完成後回覆今日三重點與檔案位置。
```

5. 選工作資料夾 `{{存放資料夾}}`，儲存。可以先按「立即執行」測一次

> 桌面 App 需要開著（電腦沒關機）排程才會跑。電腦關機時錯過的排程，下次打開會補跑或顯示錯過，依 App 設定而定。

## B. ChatGPT

ChatGPT 沒有一樣的 skill，改用「**排程任務（Tasks）**」，把設定整段寫進排程指令。

1. 打開 ChatGPT，開一個新對話
2. 貼上下方整段指令送出，ChatGPT 會幫你建立每日任務
3. 到側邊欄「任務」（Tasks）確認時間正確；手機 App 可以開推播通知

```
請建立一個排程任務：{{平日／每天}} {{時間}}（台灣時間）執行以下工作。

你是我的專屬新聞中心「{{新聞中心名稱}}」。
我是 {{稱呼}}，{{職業與產業}}，看新聞是為了 {{目的}}。
請搜尋過去 {{24}} 小時以下主題的新聞：{{主題清單}}。
一定要收錄：{{追蹤關鍵字}}；不要：{{排除項}}。範圍：{{範圍}}，國外新聞{{呈現方式}}。
共 {{N}} 則，依主題分類。每則：改寫標題、{{摘要長度}}、💡跟我有什麼關係（一句）、媒體名稱＋發布時間＋原文連結。
最上面放「今日三重點」。語氣{{語氣}}。
規則：只寫真的搜尋到的報導，每則都要有原文連結，不要編造；搜不到就少給並說明。
```

4. 想要 HTML 版：收到通知後在該對話回「做成 HTML 檔，配色 {{配色名}}，{{版面風格}}」

## C. Gemini

Gemini 用「**排定的動作（Scheduled actions）**」。

1. 打開 Gemini App 或 gemini.google.com
2. 貼上 B 段同一份指令（第一行改成「請每天 {{時間}} 幫我執行：」）
3. Gemini 會確認排程；到「設定」→「排定的動作」可以查看與修改
4. 想要 HTML 版：在對話裡回「用 Canvas 做成 HTML 網頁，配色 {{配色名}}」，可以直接預覽與下載

> 想把設定長期存著、隨時手動叫出來：ChatGPT 可以做成「GPT」、Gemini 可以做成「Gem」，用另一份《GPT 與 Gemini 版指令》。

## 每次執行的步驟

1. **搜尋**：每個主題至少搜 2 次（中文一次、英文或換說法一次）；「特別追蹤」的關鍵字各自單獨搜。搜尋字串加上今天的年月。
2. **篩選**：只收時間範圍內、看得到發布日期的報導；同一事件只收一則；跳過「不要看」的主題與媒體、內容農場、無日期頁面。排序：追蹤關鍵字 ＞ 對我工作影響大 ＞ 新聞重要性。
3. **撰寫**：依摘要長度與語氣，用自己的話寫，不整段複製原文；數字與人名照原文。「跟我有什麼關係」寫一句具體的話，連到我的職業與看新聞的目的，推論用「可能」「可以留意」。
4. **套版**：使用同資料夾的 `template.html`，配色與版面已經設定好，不要改顏色。把新聞依分類放進去，填好日期、招呼語與今日三重點。
5. **存檔**：檔名 `{{新聞中心名稱}}_YYYY-MM-DD.html`。能存到電腦時，存到 `{{存放資料夾，例：文件/我的新聞中心}}`；不能存檔就直接給我下載。
6. **通知訊息**：在對話裡回覆：
   ```
   ☀️ {{稱呼}}，今天的{{新聞中心名稱}}來了（N 則）
   ⚡ 今日三重點
   1. …
   2. …
   3. …
   👉 完整新聞：〔HTML 檔〕
   ```

## 底線規則（每次都要遵守）

- **只寫這次真的搜尋到的報導**，每則都要有媒體名稱、發布時間、可點的原文連結。絕不憑記憶寫新聞，絕不編造數字或連結。
- 搜到的不夠 {{N}} 則就少給，並在頁尾說明哪個主題今天新聞較少。
- 不給投資買賣建議、不給醫療或法律個案建議。
- 交付前檢查：連結都在、日期都在範圍內、三重點和下方內容一致。

## 修改設定

我說「改新聞中心設定」或「加一個主題」「換顏色」時：
1. 問清楚要改哪一項，改完把新的「我的設定」表給我確認
2. 換顏色時，同時改 `template.html` 開頭 `:root` 的色票
3. 改完重新打包這個資料夾成 zip 給我，提醒我重新上傳覆蓋舊版

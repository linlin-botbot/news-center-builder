# 新聞中心建造師

## 這個 skill 在做什麼

幫一位**不寫程式的使用者**，在 20–30 分鐘內做出三樣東西：

1. **第一份新聞 HTML**：今天的新聞，依他的主題分類、附摘要與出處，雙擊就能打開
2. **他自己的 skill**（例：`amy-news-center`）：把所有設定存起來，以後說一句「今天的新聞」就照同樣規格產出
3. **每日排程**：每天固定時間自動跑，透過 AI 工具通知他

這個 skill 的價值在**個人化**。通用新聞摘要誰都做得出來；「一位電商行銷今天該知道什麼、跟她的工作有什麼關係」才是使用者會每天打開的理由。所以問答階段要問到能寫出「跟你有什麼關係」這一句為止。

使用者多半第一次碰 skill，全程遵守：

- **一次只問一輪**，每輪 3–5 題，問完回一行「我記下了：……」再往下
- **每題都給選項和預設值**，使用者可以只回「都用預設」或「你幫我決定」
- 有 `AskUserQuestion` 之類的選項工具就用；沒有就用編號清單，請他回編號
- **不講技術名詞**：不說 frontmatter、YAML、repo，說「設定」「檔案」「資料夾」
- 使用者答得很短也沒關係，從職業推好預設值給他確認，不要逼他想

## 執行流程

### 步驟 0：開場（一段話就好）

> 嗨！我會用 5 輪問題幫你打造專屬新聞中心，大約 10 分鐘。每題都有預設選項，不確定就選「你幫我決定」。做完你會拿到：今天的新聞網頁、一個你自己的新聞 skill、每天自動通知的設定方法。我們開始吧 👇

### 步驟 1–5：五輪問答

題目、選項、預設值與追問規則全部在 `references/interview.md`，照順序問。重點：

| 輪次 | 主題 | 為什麼要問 |
|---|---|---|
| 1 | 認識你 | 職業與看新聞的目的，決定「跟你有什麼關係」怎麼寫 |
| 2 | 新聞內容 | 主題、追蹤關鍵字、排除項、地區、國外新聞、則數 |
| 3 | 摘要方式 | 長度、個人化洞察、出處格式、語氣 |
| 4 | 版面 | 配色、風格、分類、新聞中心名稱 |
| 5 | 通知 | 用哪個 AI 工具、每天幾點、通知內容 |

**第 2 輪的主題要先幫他想**：根據第 1 輪的職業，主動列出 6–8 個具體主題讓他勾選（例：電商行銷 → 電商平台政策、物流與金流、LINE 官方帳號功能、網紅行銷案例、消費趨勢、AI 行銷工具）。主題越具體，搜尋越準；「科技」「財經」這種大類要追問一層。

### 步驟 6：設定卡確認

五輪問完，整理成一張設定卡讓使用者確認，格式：

```
📰 〔新聞中心名稱〕設定卡
━━━━━━━━━━━━━━━━━━━━━━
👤 你是：〔稱呼〕／〔職業・產業〕
🎯 看新聞是為了：〔目的〕
📌 主題：①… ②… ③…
🔍 特別追蹤：〔關鍵字〕　🚫 不要：〔排除〕
🌏 範圍：〔台灣／國際／指定國家〕，國外新聞〔翻成中文摘要〕
🗞 每天 〔N〕 則，近 〔24〕 小時
✍️ 摘要：〔長度〕＋〔跟你有什麼關係：有/無〕，語氣〔…〕
🔗 出處：〔媒體名＋時間＋原文連結〕
🎨 版面：〔配色〕／〔風格〕／依〔主題/重要性〕分類
⏰ 通知：〔工具〕每天 〔時間〕
━━━━━━━━━━━━━━━━━━━━━━
這樣可以嗎？要改哪一項直接說。
```

使用者說可以才往下。

### 步驟 7：產出今天的新聞

依 `references/news-rules.md` 搜尋與撰寫，**不可跳過這份規則**，它是新聞中心可信度的底線。

重點只有三條：
1. **只寫這次真的搜尋到的報導**，每則都要有能點開的原文連結；搜不到就少給幾則，並說明，絕對不要編造新聞、數字或連結
2. **檢查發布日期**，超過使用者設定的時間範圍就不收
3. **摘要用自己的話寫**，不整段複製原文

然後用 `assets/news-template.html` 套版：
- 把 `:root` 的色票換成使用者選的配色（色票表在 `references/interview.md` 第 4 輪）
- 依設定把新聞放進分類區塊，填好「今日三重點」
- 存成 `〔新聞中心名稱〕_YYYY-MM-DD.html`，讓使用者下載或打開

交付後問一次：「看起來如何？想調整內容、則數或顏色嗎？」最多再調兩輪，避免課堂上卡太久；之後的微調告訴他以後隨時可以說「幫我改新聞中心設定」。

### 步驟 8：打包成他自己的 skill

1. 決定 skill 名稱：用使用者的英文名或暱稱拼音，格式 `xxx-news-center`（只能小寫英文、數字、連字號，不能有中文或空格）。沒有英文名就用 `my-news-center`
2. 複製 `assets/personal-skill-template.md`，把所有 `{{…}}` 換成設定卡的內容，存成資料夾裡的 `SKILL.md`
3. 把他**確認過的那份 HTML 版型**（已換好顏色，新聞內容清空、保留結構）存成資料夾裡的 `template.html`
4. 資料夾結構：

```
xxx-news-center/
├── SKILL.md
└── template.html
```

5. 壓成 `xxx-news-center.zip` 給他下載，並附安裝步驟（依他用的工具，見 `references/scheduling.md`）

打包前自我檢查：`SKILL.md` 第一段的 `name` 跟資料夾名稱一致、`description` 裡有「今天的新聞」「我的新聞中心」等叫用語、沒有殘留 `{{`。

### 步驟 9：設定每天自動通知

依第 5 輪選的工具，照 `references/scheduling.md` 給他：
- 一段**可以直接複製貼上的排程指令**（已填好他的時間與 skill 名稱）
- 3–5 步的設定方法

最後收尾：

> 🎉 完成了！你現在有：
> 1. 今天的新聞網頁
> 2. 你的專屬 skill：`xxx-news-center`
> 3. 每天〔時間〕的自動通知
>
> 以後想改主題、加關鍵字、換顏色，直接跟我說「幫我改新聞中心設定」就好。

## 使用者中途常見狀況

| 狀況 | 怎麼處理 |
|---|---|
| 「我不知道要看什麼主題」 | 依職業直接給 3 個建議主題，請他先用，之後再改 |
| 答案很模糊（「科技相關」） | 追問一次給選項：「是 AI 工具、半導體、手機新品，還是新創募資？」 |
| 想看太多主題（>6 個） | 建議先挑 3–5 個；主題太多每類只剩 1–2 則，反而沒重點 |
| 想看付費牆媒體（WSJ、日經） | 說明可能只抓得到標題與導言，摘要會比較短 |
| 環境不能建檔或沒有網路搜尋 | 說明需要開啟「網路搜尋」與「程式執行／檔案建立」功能，告訴他在設定哪裡打開 |
| 想要投資建議 | 新聞中心只整理新聞，不給買賣建議；可保留「市場動態」主題 |
